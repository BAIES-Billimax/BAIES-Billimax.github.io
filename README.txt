BAIES / Billimax website — GitHub Pages package (v3)

Files:
- index.html
- .nojekyll

Publish on GitHub Pages:
1. Extract this ZIP.
2. Upload index.html and .nojekyll to the ROOT of your GitHub repository.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch: main, folder: /(root), then Save.
6. Wait a few minutes for GitHub to publish the site.

This version removes the standalone “BAIES is the company. Billimax is the product.” section and replaces the two simpler illustrations with higher-fidelity workflow UI mockups for pre-walkout/pre-claim readiness and patient opportunity follow-up.
