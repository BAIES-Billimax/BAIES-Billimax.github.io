BAIES First Landing Page

index.html is a complete responsive one-page site with no build step.

Quickest publishing options:
1. Netlify Drop: open https://app.netlify.com/drop and drag index.html onto the page.
2. GitHub Pages: upload index.html to a repository, then enable Settings > Pages.
3. Custom domain: connect your Baies domain to either host.

Before publishing:
- Confirm you want your current email and phone number public.
- Replace them with a Baies-domain email if available.
- Consider adding a privacy policy before any production data collection.
